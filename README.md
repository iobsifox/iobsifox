# ObsiFox

## Product engineering for commerce, support and connected applications

ObsiFox develops WordPress and WooCommerce products, cross-platform applications, release infrastructure and game integrations.

Staffwind is the product and application publishing division of ObsiFox.

## Development areas

- WordPress and WooCommerce product development
- Flutter applications for desktop and Android
- TypeScript services and connected clients
- Minecraft and game-commerce integrations
- Signed installers, checksums and update metadata
- Persian, RTL and international user interfaces

---

## Repository standards

- Public project repositories use the original product name.
- Private implementation repositories use the `Project-Source` format.
- Every public project states its current version and release channel.
- Language percentages are calculated from tracked source files.
- Beta and Snapshot products are not presented as stable releases.
